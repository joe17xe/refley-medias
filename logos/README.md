# Logos partenaires

**Le dépôt de référence pour les agents.** Le maître des logos est le Kit de
communication de la plateforme Solid'Pilot (bucket `communication`), mais ce
bucket est **privé** et son domaine est refusé par la politique réseau des
environnements d'exécution : aucun agent ne peut l'atteindre. Ce dossier est
la copie de travail, lisible par n'importe quel outil à une URL directe.

Nommage : le nom court du partenaire, en minuscules, sans accent.

## Règles d'usage

1. **Sur fond sombre, pastille ou cartouche clair.** La plupart de ces logos
   portent du texte noir : détourés sur un fond foncé, ils disparaissent à
   moitié.
2. **On ne recolore pas, on n'inverse pas, on ne déforme pas** le logo d'un
   partenaire. S'il ne tient pas, on lui donne un fond, pas une autre couleur.
3. **Ordre d'affichage** : celui de l'en-tête de la fiche projet dans
   `docs/communication/projets/` du dépôt REFLEYFR, jamais un autre.
4. **Le logo du ministère est un bloc-marque d'État** : taille minimale, zone
   de protection, pas de déformation. Utiliser le fichier officiel fourni
   avec la convention de financement, jamais une image trouvée en ligne.
5. **Un bandeau partenaires incomplet ne se publie pas** quand il manque un
   financeur. Mieux vaut citer les partenaires en toutes lettres.
