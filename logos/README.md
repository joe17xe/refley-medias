# Logos partenaires

| Fichier | Provenance | Usage |
| --- | --- | --- |
| `ycid-logo-extrait-capture.png` | **Détouré d'une capture d'écran**, pas du fichier maître. Le maître est dans le Kit de communication de la plateforme Solid'Pilot (bucket `communication`), hors d'atteinte depuis l'environnement de production : `ycid.fr` comme le domaine Supabase sont refusés par la politique réseau. | Dépannage. 520×520, fond blanc, pas de transparence. Suffisant pour une pastille de 300 px dans une vidéo ; **à remplacer par le fichier maître** pour toute impression ou tout grand format. |

**Le logo d'YCID porte du texte noir** sur fond transparent ou blanc. Sur un
fond sombre, il se pose sur une pastille blanche — jamais recoloré, jamais
détouré en blanc : on n'altère pas la marque d'un partenaire.
